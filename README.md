# CafeSimulator
CafeSimulator — это 2D-игра в жанре симулятора кафе, разработанная на игровом движке Unity с использованием языка C#. Игрок выступает в роли бариста, задача которого — правильно и своевременно обслуживать посетителей, собирая заказы методом перетаскивания.

Ключевые особенности:

- Три уровня сложности (с каждым уровнем время на выполнение заказа уменьшается, а количество позиций в заказе увеличивается).
- Система жизней (три жизни, потеря при ошибке или истечении времени).
- Счётчик успешных заказов (три успешных заказа подряд повышают уровень).
- Экран «GAME OVER» с возможностью начать заново или вернуться в меню.
- Пиксельная графика.
- Фоновая музыка и звуковые эффекты с возможностью отключения.
- Управление: перетаскивание объектов мышью.

Использованные технологии
Разработка игры «CafeSimulator» осуществлялась с использованием игрового движка Unity 2022 LTS. Языком программирования выбран C#.  Анимации персонажей и объектов создавались через систему Animator. Звуковое сопровождение, включающее фоновую музыку и звуковые эффекты, реализовано с использованием компонента AudioSource. Для контроля версий и хостинга проекта применялись Git и платформа GitHub.

Инструкция по запуску
Для запуска готовой сборки игры необходимо перейти в раздел Releases репозитория на GitHub, скачать последнюю версию архива и распаковать его в любую папку на компьютере. После этого следует запустить исполняемый файл CafeSimulator.exe. Для запуска проекта в режиме разработчика необходимо склонировать репозиторий с помощью команды git clone, открыть проект в Unity Editor версии 2022 LTS или выше и нажать кнопку Play в редакторе. Если игра не запускается, необходимо убедиться, что на компьютере установлены соответствующие компоненты .NET Framework и Visual C++ Redistributable, которые обычно уже присутствуют в операционных системах Windows 10 и 11.
